SKY EXPLORER VR — 2.0.1
Proyecto completo para reemplazar los archivos de la raíz de Sky-Explorer-VR.
Todos los recursos e importaciones son locales y no necesitan compilación.

PUBLICAR DESDE IPHONE
1. Guarda el ZIP en Archivos y tócalo para descomprimirlo.
2. En GitHub abre IzayTO/Sky-Explorer-VR, rama main, raíz del repositorio.
3. Add file > Upload files. Selecciona TODOS los archivos dentro de la carpeta
   extraída. No subas el ZIP ni la carpeta contenedora creada por iOS.
4. Commit changes. Espera que termine el despliegue de GitHub Pages.
5. Abre el enlace Pages en el navegador del Quest, con conexión a internet.
6. Cuando aparezca la actualización, acepta Guardar y recargar. La descarga
   offline se instala como un conjunto completo con verificación de hashes.
7. En Y > Sistema > Sesión > Diagnóstico debe indicar VR-2.0.1.

GitHub se utilizó únicamente para lectura. Este archivo no publica nada.
Conserva tus datos guardados del mismo origen y ruta; no borres los datos del
navegador. Si deseas una copia adicional, exporta la expedición desde Sesión.

Consulta GUIA-VR.txt para postura, lámparas y freno/reversa.
Se incluyen los 70 archivos completos del proyecto y la caché actualizada.
Los módulos y recursos originales siguen presentes, sin carpetas nuevas.
