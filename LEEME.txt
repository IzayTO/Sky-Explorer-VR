QUÉ CAMBIA
- Ayudas redondeadas junto a cada mano, según la acción actual. Se elimina
  el cartel inferior permanente. Solo la carga de destino tiene texto frontal.
- Manos en tono piel mate, sin añadir luces, reflejos ni efectos de brillo.
- Menú de muñeca 10% menor; paneles de opciones 20% menores.
- Barras numéricas: apunta y mantén gatillo derecho para arrastrar. Suelta
  para terminar; también sirven el joystick y A para escribir un valor exacto.
- Rayo y punto visibles por delante del menú; fuera conservan oclusión del mundo.
- Menos cálculo de sombras de lámparas y mejor reutilización de su caché.
- Se conservan brillo, alcance, colores, sombras, construcciones, relieve,
  controles, instrumentos, vehículos, guardados y preferencias existentes.

PASOS PARA ISAI — QUÉ HAGO AHORA
1. Guarda el ZIP en Archivos y tócalo para descomprimir.
2. En GitHub abre IzayTO/Sky-Explorer-VR → Add file → Upload files.
3. Selecciona los 12 archivos sueltos de esta carpeta. Súbelos juntos en la
   raíz, donde ya está index.html. No subas la carpeta ni el ZIP.
4. Pulsa Commit changes. Se reemplazan los nombres existentes y se añade
   vr-hand-guides.js. No borres previamente los otros archivos.
5. Espera a que Actions → pages build and deployment termine correctamente.
   Settings → Pages debe seguir en main / (root). GitHub publica automáticamente.
6. En Quest Browser, con Internet, abre:
   https://izayto.github.io/Sky-Explorer-VR/
7. Espera la descarga. Cuando aparezca Actualización lista → Guardar y recargar,
   pulsa ese botón. Desde VR: Y → Sistema → Versión offline permite aplicarla
   saliendo primero al navegador. Cierra otras pestañas antiguas de este juego.
8. Entra en VR → Y → Sistema → Diagnóstico. Debe indicar VR-1.0.1 y WebGL2 / WebXR.
   Espera Disponible sin conexión antes de probar sin Internet.
9. En Catálogo prueba la barra Cantidad. Al mover las manos, las ayudas deben
   acompañarlas sin saltos. Enciende las mismas lámparas de tu base para comparar.

SI APARECE LA VERSIÓN ANTIGUA
Cierra las pestañas del juego, vuelve a abrir la URL con Internet y recarga.
Si aún ocurre, abre:
https://izayto.github.io/Sky-Explorer-VR/?diagnostico=1
Usa Buscar actualización. Como último recurso del propio panel usa
Restablecer solo la caché offline. Esto vuelve a descargar los recursos y
conserva las partidas. No borres los datos del sitio desde el navegador.
El diagnóstico puede mostrar el hash de la caché además de VR-1.0.1.

No necesitas Python, Node, Unity, terminal ni compilar. El Service Worker ya
está regenerado para el conjunto completo de recursos de esta actualización.
El paquete no cambia las claves sky-vr-* ni el formato de las expediciones.
Conserva tu ZIP anterior y, si quieres respaldo adicional, exporta tu expedición
antes de actualizar. Una vuelta al paquete completo anterior también debe
incluir su propio service-worker.js; no mezcles archivos de distintas versiones.

GUIA-VR.txt: controles. CAMBIOS-VR.txt: detalles técnicos.
VERIFICACION-VR.txt: pruebas, mediciones locales y límites.
